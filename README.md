# Vion Lunch Menu

Система заказа офисных обедов: сотрудники выбирают обеды на неделю вперёд,
админ получает ежедневную сводку в 9:30 (Кишинёв) и выгружает месячный
отчёт для бухгалтерии. Интерфейс на русском и румынском.

Next.js 16 · Supabase (Postgres + вход по коду из письма) · Vercel · Resend.

## Настройка

### 1. Supabase

1. Создайте проект на <https://supabase.com> (регион — Frankfurt).
2. **SQL Editor** → выполните по очереди файлы из `supabase/migrations/`.
3. **Authentication → Sign In / Providers → Email**: включён; *Confirm email* — можно оставить.
4. **Authentication → Emails → Templates → Magic Link** — замените текст письма,
   чтобы в нём были и код, и ссылка:

   ```html
   <h2>Вход в «Обеды» / Prânzuri</h2>
   <p>Код / Codul: <b style="font-size:24px">{{ .Token }}</b></p>
   <p><a href="{{ .SiteURL }}/auth/confirm?token_hash={{ .TokenHash }}&type=email">Войти / Intră</a></p>
   ```

5. **Authentication → URL Configuration → Site URL** — адрес сайта на Vercel.
6. Встроенная почта Supabase отправляет лишь несколько писем в час. Для работы
   подключите SMTP: **Authentication → Emails → SMTP Settings** (например, SMTP Resend:
   host `smtp.resend.com`, port `465`, user `resend`, password — API-ключ Resend).

### 2. Переменные окружения

Скопируйте `.env.example` в `.env.local` и заполните. На Vercel — те же
переменные в **Project → Settings → Environment Variables**.

`BOOTSTRAP_ADMIN_EMAIL` — e-mail первого администратора: при первом входе
он создаётся автоматически. Остальных сотрудников добавляет администратор.

### 3. Почта для сводки (Resend)

1. Зарегистрируйтесь на <https://resend.com>, добавьте и подтвердите домен компании
   (без подтверждённого домена Resend отправляет письма только на ваш собственный адрес).
2. Создайте API-ключ → `RESEND_API_KEY`; `MAIL_FROM` — адрес на этом домене.

### 4. Автоматическая отправка в 9:30 (pg_cron)

На тарифе Vercel Hobby cron срабатывает с точностью до часа, поэтому расписание
ведёт Supabase:

1. **Database → Extensions** — включите `pg_cron` и `pg_net`.
2. Придумайте длинный случайный `CRON_SECRET` и добавьте его в переменные Vercel.
3. Откройте `supabase/cron.sql`, подставьте адрес сайта и секрет, выполните в SQL Editor.

Задание вызывает `/api/cron/daily-summary` каждые 15 минут утром по будням;
приложение отправляет сводку один раз, когда по Кишинёву наступило время отправки
(по умолчанию 9:30) и на сегодня есть меню. Летнее/зимнее время учитывается
автоматически. Кому слать (админу или поставщику + копия админу), время блокировки
и отправки, долю компании — меняет администратор в **Настройках**.
Сводку можно отправить вручную со страницы **Сегодня**.

### 5. Деплой на Vercel

1. Импортируйте репозиторий в Vercel (Framework: Next.js).
2. Добавьте переменные окружения из `.env.example`.
3. После первого деплоя укажите этот адрес в Supabase (Site URL) и в `supabase/cron.sql`.

### 6. Локальный запуск

```bash
npm install
npm run dev      # http://localhost:3000
npm test         # тесты (логика + миграции на встроенном Postgres)
```

## Как пользоваться

**Администратор:** Настройки → цены → Меню (неделя: первое, второе A и B; пустой день =
выходной) → Сотрудники (вручную или импорт Excel: столбцы Имя, E-mail, Телефон,
Отдел, Активен) → Сегодня (сводка, правка заказов, отправка) → Отчёт (Excel за месяц).

**Сотрудник:** входит по e-mail (код или ссылка из письма), выбирает на каждый день
A/B, с первым или без, либо «не заказываю». До 9:15 текущего дня выбор можно менять.
В «Истории» видны заказы и суммы за месяц: всего, доля компании, удержание.

## Структура

- `supabase/migrations/` — схема базы
- `src/lib/` — доступ к данным, авторизация, бизнес-логика
- `src/app/(app)/` — страницы для вошедших пользователей, `admin/` — админка
- `src/i18n/` — переводы ru/ro
